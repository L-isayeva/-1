# Документация по проектной практике

В данной папке размещены основные материалы по прохождению проектной (учебной) практики в формате Markdown.

## Состав папки

- `README.md` — описание содержимого папки и структуры документации
- `practice_documentation.md` — основная документация по выполнению базовой части практики
- `progress_log.md` — журнал прогресса по этапам работы
- `partner_report.md` — отчёт о взаимодействии с заказчиком проекта
- `open_source_contribution.md` — описание вариативной части, связанной с вкладом в открытый проект

## Назначение документации

Документация в данной папке отражает:
- процесс выполнения базовой части проектной практики;
- этапы разработки репозитория и сайта;
- сведения о заказчике проекта;
- особенности вариативной части;
- результаты, полученные в ходе практики.

Все материалы оформлены в формате Markdown в соответствии с требованиями задания.
