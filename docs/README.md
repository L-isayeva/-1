# Документация по проектной практике

В данной папке размещены основные материалы по прохождению проектной (учебной) практики в формате Markdown.

## Состав папки

- `README.md` — описание содержимого папки
- `practice_documentation.md` — основная документация по практике
- `progress_log.md` — журнал выполнения работы
- `partner_report.md` — отчёт о взаимодействии с заказчиком / партнёрской стороной
- `open_source_contribution.md` — описание вариативной части, связанной с вкладом в открытый проект

## Назначение документации

Документация отражает:
- содержание базовой части практики;
- ход выполнения проекта;
- сведения о заказчике проекта;
- результаты вариативной части;
- подготовку итогового отчёта по практике.
