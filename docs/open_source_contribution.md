# Вариативная часть. Вклад в открытый проект на GitHub

## Формулировка задания
В рамках вариативной части требовалось выбрать открытый проект на GitHub или GitVerse, изучить его структуру и задокументировать собственный вклад или подготовку к вкладу.

## Цель вариативной части
Познакомиться с основами open-source разработки, изучить устройство открытого репозитория, освоить базовые действия по подготовке вклада и зафиксировать результаты в документации.

## Что было изучено
1. Структура открытого репозитория.
2. Назначение README и вспомогательных файлов.
3. Использование fork, branch, commit и pull request.
4. Логика внесения изменений в документацию и код.
5. Принципы взаимодействия с открытым сообществом разработчиков.

## Выполненные действия
- проведён анализ открытого репозитория;
- изучены правила участия;
- рассмотрены возможные форматы вклада;
- подготовлено описание порядка внесения изменений;
- зафиксированы полученные навыки и выводы.

## Полученные навыки
- навигация по открытому репозиторию;
- понимание структуры open-source проекта;
- работа с базовой механикой Git и GitHub;
- подготовка документации по собственному вкладу;
- анализ требований к совместной разработке.

## Вывод
Выполнение вариативной части позволило получить представление о принципах open-source разработки и о порядке внесения вклада в открытые проекты.
