# Документация по проектной (учебной) практике

## Общая информация

Проектная (учебная) практика выполнялась индивидуально в рамках проекта «Лаборатория успеха» по дисциплине «Проектная деятельность».

Проект относится к направлению IT и имеет стратегический характер. Заказчиком проекта выступает ITE Group, а контактным лицом со стороны заказчика является Нагорнова Ирина Викторовна.

## Актуальность и проблематика проекта

Проект связан с темой применения геймификации в сфере дополнительного образования. Актуальность проекта определяется тем, что геймификация является эффективным методом мотивации к профессиональному развитию, однако качественные варианты её использования в дополнительном образовании для развития управленческих, экономических, профессиональных и коммуникационных навыков представлены в недостаточном объёме.

## Цель проекта

Разработать варианты применения геймификации в сфере дополнительного образования кадров и создать прототип.

## Продуктовый результат

Итоговым продуктовым результатом проекта является игровой продукт. Промежуточным продуктовым результатом выступают прототипы игр.

## Основные задачи практики

1. Создать и оформить git-репозиторий в соответствии с заданной структурой.
2. Подготовить документацию в формате Markdown.
3. Разработать статический сайт проекта на HTML и CSS.
4. Оформить журнал хода выполнения практики.
5. Подготовить отчёт о взаимодействии с заказчиком или партнёрской стороной.
6. Выполнить вариативную часть по теме вклада в открытый проект на GitHub.
7. Подготовить итоговый отчёт по проектной практике.

## Выполненные этапы

### 1. Организация структуры репозитория
Была подготовлена файловая структура репозитория, включающая корневой README, папки с документацией, отчётами, сайтом, материалами задания и файлами вариативной части.

### 2. Подготовка документации
В формате Markdown были оформлены документы, отражающие цели, задачи, этапы выполнения практики, взаимодействие с заказчиком и описание вариативной части.

### 3. Создание статического сайта
Был разработан статический сайт проекта с основными разделами: главная страница, описание проекта, участник, журнал, ресурсы, сведения о заказчике и страница вариативной части.

### 4. Изучение проектных материалов
Были изучены паспорт проекта и отчёт по проектной деятельности, что позволило уточнить проблематику проекта, его цель, задачи, этапы реализации и промежуточные результаты.

### 5. Выполнение вариативной части
В рамках вариативной части был выбран открытый проект на GitHub, изучены его структура и особенности, а также подготовлено описание собственного вклада и полученных навыков.

## Основные результаты

По итогам практики был подготовлен структурированный репозиторий с документацией, статическим сайтом и материалами вариативной части. Практика позволила сформировать навыки работы с Git, Markdown, HTML, CSS и познакомиться с основами участия в open-source проектах.
