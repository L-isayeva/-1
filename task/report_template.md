# Шаблон итогового отчёта по проектной практике

## Титульная часть

- Федеральное государственное автономное образовательное учреждение высшего образования
- Московский политехнический университет
- Факультет
- Кафедра
- Направление подготовки / специальность
- Название: **ОТЧЁТ по проектной практике**
- ФИО студента
- Группа
- Место прохождения практики
- Руководитель практики
- Год оформления

---

## ОГЛАВЛЕНИЕ

1. Введение  
2. Общая информация о проекте  
   - Название проекта  
   - Цели и задачи проекта  
3. Общая характеристика деятельности организации (заказчика проекта)  
   - Наименование заказчика  
   - Организационная структура  
   - Описание деятельности  
4. Описание задания по проектной практике  
5. Описание достигнутых результатов по проектной практике  
6. Заключение  
7. Список использованной литературы  
8. Приложения  

---

## ВВЕДЕНИЕ

Во введении необходимо кратко описать:
- в рамках какого проекта проходила практика;
- какова общая направленность практики;
- какие навыки и задачи являлись основными;
- с чем была связана работа в ходе практики.

---

## ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ

### Название проекта
Указать официальное название проекта.

### Цели и задачи проекта
Кратко сформулировать:
- цель проекта;
- основные задачи;
- общую направленность проектной деятельности.

---

## ОБЩАЯ ХАРАКТЕРИСТИКА ДЕЯТЕЛЬНОСТИ ОРГАНИЗАЦИИ (ЗАКАЗЧИКА ПРОЕКТА)

### Наименование заказчика
Указать организацию-заказчика.

### Организационная структура
Кратко описать положение заказчика в рамках проекта и взаимодействия.

### Описание деятельности
Показать, в чём заключается интерес заказчика к проекту и как проект соотносится с его задачами.

---

## ОПИСАНИЕ ЗАДАНИЯ ПО ПРОЕКТНОЙ ПРАКТИКЕ

В данном разделе необходимо описать:
- базовую часть задания;
- какие действия были выполнены в рамках практики;
- какая вариативная часть была выбрана;
- какие инструменты использовались.

---

## ОПИСАНИЕ ДОСТИГНУТЫХ РЕЗУЛЬТАТОВ ПО ПРОЕКТНОЙ ПРАКТИКЕ

В данном разделе нужно описать:
- структуру созданного репозитория;
- подготовленную документацию;
- сайт проекта;
- работу с материалами проекта;
- результаты вариативной части;
- общий итог выполненной работы.

---

## ЗАКЛЮЧЕНИЕ

В заключении необходимо:
- подвести итоги проделанной работы;
- кратко оценить полученные навыки;
- описать значение выполненных задач для проекта и заказчика.

---

## СПИСОК ИСПОЛЬЗОВАННОЙ ЛИТЕРАТУРЫ

Необходимо указать:
- паспорт проекта;
- отчёт по проектной деятельности;
- документацию по Git;
- документацию по HTML и CSS;
- материалы по Markdown;
- другие использованные источники при необходимости.

---

## ПРИЛОЖЕНИЯ

В приложения могут быть включены:
- скриншоты сайта;
- структура репозитория;
- дополнительные материалы проекта;
- фрагменты документации;
- иные материалы при необходимости.
