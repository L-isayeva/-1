
# Задание на проектную (учебную) практику

## Общая информация

Проектная (учебная) практика предназначена для студентов первого курса, обучающихся по направлениям, связанным с информационными технологиями и информационной безопасностью. Общая трудоёмкость практики составляет 72 академических часа.

Практика может выполняться индивидуально или в составе группы до 3 человек. Для управления версиями используется **Git**, для написания документации — **Markdown**, а для создания статического веб-сайта — **HTML** и **CSS**. Допускается использование генераторов статических сайтов, однако в рамках данного проекта сайт был создан на HTML и CSS.

## Структура задания

Задание состоит из двух частей:
1. **Базовая часть** — обязательна для всех студентов.
2. **Вариативная часть** — определяется отдельно и согласуется с ответственными по практике.

---

## Базовая часть задания

### 1. Настройка Git и репозитория
Необходимо:
- создать личный или групповой репозиторий;
- освоить базовые команды Git;
- использовать коммиты для фиксации изменений;
- организовать структуру репозитория в соответствии с требованиями.

**Ожидаемое время:** 5 часов.

### 2. Написание документов в Markdown
Необходимо:
- подготовить документацию в формате Markdown;
- оформить описание проекта, журнал прогресса и другие материалы;
- структурировать текстовую часть репозитория.

**Ожидаемое время:** 5 часов.

### 3. Создание статического веб-сайта
Необходимо:
- создать статический сайт проекта;
- использовать HTML и CSS;
- сделать сайт уникальным по структуре и наполнению;
- включить основные разделы проекта.

Сайт должен содержать:
- главную страницу с аннотацией проекта;
- страницу «О проекте»;
- страницу или раздел с участниками и личным вкладом;
- страницу или раздел «Журнал» минимум с тремя постами;
- страницу «Ресурсы»;
- материалы, раскрывающие суть проекта;
- графические и другие медиа-элементы при необходимости.

**Ожидаемое время:**  
изучение и настройка — 10–14 часов,  
дизайн и наполнение — 4–8 часов.

### 4. Взаимодействие с организацией-партнёром / заказчиком
Необходимо:
- организовать взаимодействие с партнёрской стороной;
- изучить прикладной контекст проекта;
- подготовить Markdown-отчёт по итогам взаимодействия;
- добавить отчёт в репозиторий и при необходимости отразить информацию на сайте.

**Ожидаемое время:**  
взаимодействие — 4 часа,  
написание отчёта — 4 часа.

### 5. Отчёт по практике
Необходимо:
- подготовить итоговый отчёт по структуре кафедрального шаблона;
- разместить отчёт в папке `reports`;
- оформить версии в форматах DOCX и PDF;
- загрузить итоговые файлы в LMS.

---

## Вариативная часть задания

В рамках данного проекта выбран **вариант 3**:  
**вклад в открытый проект на GitHub или GitVerse**.

Вариативная часть предполагает:
- изучение открытого проекта;
- знакомство со структурой репозитория;
- анализ процесса open-source разработки;
- документирование собственного вклада или подготовки к нему.

---

## Требования к репозиторию

Репозиторий должен содержать:
- корневой `README.md`;
- папку `docs/` с Markdown-документацией;
- папку `reports/` с отчётами;
- папку `site/` со статическим сайтом;
- папку `task/` с текстом задания и шаблоном отчёта;
- дополнительные папки при необходимости.

---

## Итоговый результат

По завершении практики должны быть подготовлены:
- структурированный git-репозиторий;
- документация в Markdown;
- статический сайт проекта;
- материалы по вариативной части;
- итоговый отчёт в DOCX и PDF.
