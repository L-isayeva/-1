# Проектная (учебная) практика

## Описание
Этот репозиторий создан для выполнения заданий проектной (учебной) практики.

## Цель
Освоить основы работы с Git, Markdown, HTML и CSS, а также представить результаты проекта в виде статического сайта.

## Основные задачи
- создать и оформить репозиторий;
- подготовить документы в формате Markdown;
- разработать статический сайт;
- описать ход выполнения проекта;
- оформить итоговые материалы по практике.

## Структура репозитория
- `README.md` — общее описание проекта
- `index.html` — главная страница сайта
- `about.html` — страница «О проекте»
- `team.html` — страница «Участники»
- `journal.html` — страница «Журнал»
- `resources.html` — страница «Ресурсы`
- `partner.html` — страница о взаимодействии с партнёром
- `css/style.css` — стили сайта
- `docs/` — документы в Markdown
- `reports/` — итоговый отчёт

## Участники
- ФИО
- Учебная группа
- Направление подготовки

## Результат
В ходе практики будет создан репозиторий с документацией и статический сайт по проекту.
