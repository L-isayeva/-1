Вариант 3: Вклад в открытый проект на GitHub

Формулировка задания

В соответствии с заданием на проектную практику вариативная часть (вариант 3) предполагает:

  1. Нахождение открытого проекта на GitHub, имеющего не менее 50 звёзд (Stars)
  2. Изучение кода проекта
  3. Внесение вклада (исправление бага или добавление новой функции)
  4. Документирование вклада в формате Markdown
