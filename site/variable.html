Формулировка задания

В рамках вариативной части требовалось выбрать открытый проект на GitHub или GitVerse, изучить его структуру, ознакомиться с принципами совместной разработки и задокументировать собственный вклад.

Цель выполнения

Познакомиться с основами open-source разработки, изучить механику взаимодействия с открытым репозиторием и получить представление о порядке внесения изменений в проект.

Что было изучено

  • структура открытого репозитория;
  • назначение README и вспомогательной документации;
  • порядок fork, branch, commit, push и pull request;
  • правила оформления вклада в open-source проект.

Результат

В рамках вариативной части был изучен открытый проект, проанализированы правила участия в нём и оформлено описание вклада в документации проектной практики.
