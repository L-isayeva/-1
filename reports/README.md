# Отчёты по проектной практике

В данной папке размещаются итоговые материалы по проектной (учебной) практике.

## Состав папки

- `README.md` — описание содержимого папки
- `report.md` — текстовая версия итогового отчёта в формате Markdown
- `report.docx` — итоговый отчёт в формате DOCX
- `report.pdf` — итоговый отчёт в формате PDF

## Назначение файлов

Файл `report.md` используется как черновая и рабочая текстовая основа итогового отчёта.  
После окончательной проверки содержание переносится в Word-документ `report.docx`, оформляется в соответствии с шаблоном кафедры и затем экспортируется в `report.pdf`.

## Примечание

Итоговый отчёт составляется на основе структуры, приведённой в файле `practice_report_template.docx`.
