# Базовая часть задания

## 1. Настройка Git и репозитория

В рамках выполнения базовой части задания был создан личный git-репозиторий с необходимой структурой папок и файлов для размещения материалов проектной практики. Репозиторий был организован таким образом, чтобы в нём отдельно располагались документация в формате Markdown, материалы сайта, отчётные файлы, текст задания и дополнительные рабочие материалы.

В процессе работы были освоены и применены базовые команды Git: клонирование репозитория, добавление файлов, фиксация изменений, отправка коммитов и работа с ветками. Изменения в репозитории сохранялись регулярно, с осмысленными сообщениями к коммитам, что позволило организовать последовательную и структурированную работу над проектом.

Использование Git обеспечило удобное хранение материалов, контроль изменений и последовательное развитие проекта в цифровой среде.

## 2. Написание документов в Markdown

Все основные материалы по практике были подготовлены в формате Markdown. Такой формат был выбран как основной для документации, поскольку он позволяет создавать структурированные, читаемые и легко редактируемые тексты, удобные для размещения в репозитории.

В процессе работы были оформлены следующие документы:
- основное описание практики;
- журнал прогресса;
- сведения о заказчике проекта;
- описание вариативной части;
- черновик итогового отчёта;
- вспомогательные файлы с описанием структуры задания и шаблонами.

Использование Markdown позволило выстроить единый стиль документации, сделать материалы понятными и логично организованными, а также упростить дальнейшую работу с текстами при подготовке итогового отчёта.

## 3. Создание статического веб-сайта

В рамках базовой части задания был разработан статический веб-сайт, посвящённый проекту «Лаборатория успеха». Для создания сайта были использованы языки разметки HTML и CSS, что позволило реализовать структуру страниц, навигацию между разделами и единое визуальное оформление без применения дополнительных сложных технологий.

При разработке сайта особое внимание уделялось тому, чтобы его содержание было связано именно с проектом, а не только с практикой. В результате сайт был оформлен как самостоятельное цифровое представление проекта, раскрывающее его идею, проблематику, цели, этапы разработки, состав команды, описание заказчика и особенности игровой механики.

На сайте были созданы следующие основные разделы:
- главная страница с аннотацией проекта;
- страница «О проекте»;
- страница «Команда проекта»;
- страница «Разработка»;
- страница «Материалы»;
- страница «Заказчик»;
- страница «Как работает игра».

Сайт был оформлен в едином визуальном стиле с использованием зелёной цветовой палитры, карточной структуры блоков, навигационного меню и адаптивной вёрстки. Это позволило сделать его не только информативным, но и удобным для восприятия. В процессе разработки были переработаны тексты страниц, усилен акцент на самом проекте и его игровом продукте, а также выстроено более цельное представление о содержании проекта.

Таким образом, сайт стал цифровой презентационной площадкой проекта «Лаборатория успеха» и важной частью его представления.

## 4. Взаимодействие с организацией-заказчиком

В рамках выполнения базовой части задания были изучены материалы, связанные с заказчиком проекта — ITE Group. На основе паспорта проекта и отчёта по проектной деятельности были уточнены проблематика проекта, его цели, ключевые задачи и ожидаемый продуктовый результат.

Анализ материалов показал, что проект ориентирован на разработку геймификационных решений в сфере дополнительного образования кадров и направлен на развитие управленческих, экономических, профессиональных и коммуникационных навыков через игровой формат.

Работа с материалами заказчика позволила:
- уточнить прикладную направленность проекта;
- определить ценность игрового продукта для заказчика;
- связать структуру сайта и документации с реальной задачей проекта;
- представить проект в более обоснованном и структурированном виде.

На основе изученных данных был подготовлен отчёт о взаимодействии с заказчиком, включённый в документацию проекта.

## 5. Отчёт по практике

По итогам выполнения базовой части задания была подготовлена текстовая основа итогового отчёта по проектной практике в соответствии с шаблоном, предложенным кафедрой. В отчёте отражены общая информация о проекте, сведения о заказчике, описание выполненных задач, достигнутые результаты и выводы о проделанной работе.

Структура отчёта была приведена в соответствие с требованиями шаблона и включила:
- введение;
- общую информацию о проекте;
- характеристику деятельности заказчика;
- описание задания по проектной практике;
- описание достигнутых результатов;
- заключение;
- список использованной литературы;
- приложения.

Подготовка отчёта позволила систематизировать результаты практики и представить их в завершённой форме для дальнейшего оформления в форматах DOCX и PDF.
